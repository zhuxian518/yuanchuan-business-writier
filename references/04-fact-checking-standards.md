# 远川商业写作事实核查标准

> 多层级核查体系与信源管理规范

---

## 一、核查重要性认知

### 1.1 为什么事实核查至关重要

在商业分析文章中,**所有涉及数据、引言、历史事件的内容都必须可追溯、可验证**。这不仅关乎文章的专业性,更是对读者负责的底线。

**一个错误数据的代价**:
- 失去读者信任
- 损害媒体/个人品牌
- 可能引发法律风险
- 影响行业声誉

**远川标准**:
> "宁可不写,也不能写错。数据不确定时,宁可用'据...报道'等限定语,也不能信口开河。"

### 1.2 常见事实错误类型

**错误类型1: 时间错误**
```
❌ 错误: "2020年,拼多多市值超过阿里..."
✅ 正确: "2023年底,拼多多市值超过阿里..."

危害: 时间节点错误会导致因果关系混乱
```

**错误类型2: 数据张冠李戴**
```
❌ 错误: 将GMV说成营收,将毛利说成净利
✅ 正确: 明确区分各类财务指标的定义

危害: 误导投资决策,损害专业度
```

**错误类型3: 因果关系臆测**
```
❌ 错误: "因为阿里的反垄断罚款,导致股价下跌..."
✅ 正确: "阿里股价下跌,反垄断罚款是影响因素之一..."

危害: 简化复杂问题,误导读者认知
```

**错误类型4: 引用断章取义**
```
❌ 错误: 只引用对自己观点有利的部分,忽略原文完整语境
✅ 正确: 完整引用或明确说明引用的语境

危害: 歪曲事实,可能引发争议
```

## 二、信源分级体系

### 2.1 一级信源(最可靠,优先使用)

**定义**: 官方、权威、原始的第一手信息

**包含范围**:
1. **上市公司财报/公告**
   - 年报、季报、招股书
   - 重大事项公告
   - 投资者关系活动记录

2. **政府官方文件/统计数据**
   - 国家统计局数据
   - 行业主管部门报告
   - 政策文件原文

3. **法院判决书/纪委通报**
   - 中国裁判文书网
   - 各级纪委官网
   - 检察院公告

4. **权威媒体调查报道**
   - 财新、财经、21世纪经济报道等
   - 必须是调查报道,非转载

**使用原则**:
- 优先引用一级信源
- 直接链接到原始文件
- 标注具体页码/段落

**示例**:
```
✅ "根据小米集团2022年Q3财报(第12页),净亏损14.7亿元..."
✅ "中国裁判文书网显示,王效金因受贿罪被判处..."
```

### 2.2 二级信源(可用,需交叉验证)

**定义**: 专业机构的研究分析或主流媒体的常规报道

**包含范围**:
1. **行业研究报告**
   - 券商研报(中信、华泰等)
   - 咨询公司报告(麦肯锡、BCG等)
   - 市场调研机构(艾瑞、易观等)

2. **主流媒体常规报道**
   - 人民日报、新华社
   - 经济观察报、第一财经
   - 36氪、虎嗅、钛媒体

3. **企业官方发布**
   - 官网新闻
   - 官方微博/微信
   - 创始人公开演讲

4. **学术论文/专业书籍**
   - 核心期刊论文
   - 行业专著
   - 知名学者研究

**使用原则**:
- 至少找到2个独立来源相互印证
- 注明信息来源和时间
- 对于关键数据,尽量追溯到一级信源

**示例**:
```
✅ "据36氪报道(2022年11月),江小白年营收约20亿元..."
✅ "艾瑞咨询《2022年中国电商行业研究报告》显示..."
```

### 2.3 三级信源(谨慎使用,需特别标注)

**定义**: 非官方、非权威的信息来源

**包含范围**:
1. **自媒体报道**
   - 个人公众号
   - 微博大V爆料
   - 知乎回答

2. **社交媒体传闻**
   - 微博热搜
   - 论坛讨论
   - 小道消息

3. **未经证实的内部消息**
   - "据内部人士透露"
   - "接近XX的人士称"
   - "匿名员工爆料"

**使用原则**:
- 必须明确标注信息来源和可信度
- 使用"据...称"、"有消息显示"等限定语
- 不可作为核心论据
- 尽快寻找一级或二级信源验证

**示例**:
```
⚠️ "据社交媒体传闻,江小白正在大规模裁员..."
⚠️ "有媒体报道称,小米造车进度不及预期..."
⚠️ "接近阿里的人士透露,内部正在进行组织调整..."
```

### 2.4 禁用信源

**绝对不可使用的信息来源**:
1. 来源不明的小道消息
2. 自己"脑补"的数据
3. 无法找到第二来源证实的"独家爆料"
4. 已被辟谣的虚假信息
5. 明显带有恶意的攻击性内容

**原则**:
> "如果一个信息无法验证,要么不写,要么明确标注为'未经证实'。"

## 三、核查执行流程

### 3.1 写作时同步核查(推荐)

**流程**:
```
写作 → 使用数据/事实 → 立即记录来源 → 贴上链接 → 继续写作
```

**工具推荐**:
- 印象笔记/Notion(边写边贴链接)
- Excel表格(分类记录来源)
- Zotero(学术引用管理)

**优点**:
- 不会遗忘来源
- 避免后期补充困难
- 提高效率

**操作示例**:
```
写作中:
"小米三季度净亏损14.7亿元"

立即操作:
1. 打开小米Q3财报PDF
2. 找到对应数据(第12页)
3. 复制链接到笔记
4. 标注: [来源: 小米集团2022年Q3财报,第12页]
```

### 3.2 完稿后系统核查

**步骤1: 标记所有待核查内容**
```
阅读全文,用不同颜色标记:
- 红色: 数据
- 黄色: 引语
- 蓝色: 事件描述
- 绿色: 因果判断
```

**步骤2: 逐一核查并分类**
```
L1(必须核查):
- 所有数据
- 所有时间节点
- 所有人名/公司名

L2(建议核查):
- 事件描述
- 因果关系
- 趋势判断

L3(标注来源):
- 行业共识
- 通用知识
- 作者观点
```

**步骤3: 交叉验证**
```
对于关键事实:
1. 至少找到2个独立来源
2. 比对信息是否一致
3. 如有出入,优先采用一级信源
4. 实在无法确认,删除或改写
```

**步骤4: 生成参考文献**
```
按以下格式整理:
[1] 文章标题,来源,发布时间,URL
[2] 报告名称,机构,日期,URL
...
```

### 3.3 核查清单模板

**数据核查清单**:
```markdown
## 待核查数据清单

| 数据内容 | 出处 | 一级信源? | 已验证? | 备注 |
|---------|------|----------|--------|------|
| 小米净亏14.7亿 | 财报 | ✅ | ✅ | Q3财报第12页 |
| 京东市占率13.5% | 艾瑞 | ❌ | ⚠️ | 需追溯原始数据 |
| ... | ... | ... | ... | ... |
```

**人物事件核查清单**:
```markdown
## 待核查人物/事件

| 内容 | 来源 | 时间 | 已验证? | 备注 |
|-----|------|------|--------|------|
| 王效金去世 | 财新 | 2023年X月 | ✅ | 裁判文书网可查 |
| 江小白裁员 | 36氪 | 2022年初 | ⚠️ | 仅有媒体报道 |
| ... | ... | ... | ... | ... |
```

## 四、特定场景核查指南

### 4.1 财报数据核查

**核查要点**:
1. **区分财务指标**
   - 营收 vs GMV
   - 毛利 vs 净利
   - 经营性现金流 vs 自由现金流

2. **统一统计口径**
   - 同比 vs 环比
   - GAAP vs Non-GAAP
   - 人民币 vs 美元

3. **注意合并范围**
   - 合并报表 vs 母公司报表
   - 持续经营 vs 包含终止经营

**操作流程**:
```
1. 打开公司官网投资者关系页面
2. 下载完整财报PDF
3. 用Ctrl+F搜索关键指标
4. 截图或复制原文
5. 标注页码和表格编号
```

**示例引用格式**:
```
"根据小米集团2022年第三季度财报(第12页),调整后净利润为21亿元,同比下降59.1%。"

参考文献:
[1] 小米集团2022年第三季度业绩公告,2022年11月23日,https://...
```

### 4.2 行业数据核查

**核查要点**:
1. **确认统计口径**
   - 覆盖范围(全国/区域)
   - 时间周期(年度/季度/月度)
   - 统计方法(抽样/全量)

2. **对比不同来源**
   - 官方统计局 vs 第三方机构
   - 不同机构的数据差异
   - 选择最权威的来源

**常用数据源**:
- 国家统计局: http://www.stats.gov.cn/
- 工信部: http://www.miit.gov.cn/
- 商务部: http://www.mofcom.gov.cn/
- 艾瑞咨询、易观、IDC等

**示例**:
```
✅ "根据国家统计局数据,2022年全国规模以上工业企业利润总额84038.5亿元,同比下降4.0%。"

⚠️ "据某机构统计,2022年工业企业利润下降..." (缺乏权威性)
```

### 4.3 人物语录核查

**核查要点**:
1. **追溯原始出处**
   - 不要引用转载的转载
   - 找到最早的报道或视频
   - 确认是直接引语还是间接转述

2. **完整呈现语境**
   - 不要断章取义
   - 说明是什么场合的发言
   - 必要时给出完整语段

3. **标注时间和场合**
   - 演讲/采访/财报电话会
   - 具体日期
   - 媒体或活动名称

**示例**:
```
❌ 错误:
"雷军说,小米要成为世界前五。"

✅ 正确:
"雷军在小米汽车发布会上表示(2021年3月):'小米造车成功的唯一途径是挤进世界前五。'"

✅ 更好:
"在2021年3月的小米汽车发布会上,雷军明确表态:'为什么我们还要做?因为我深知,小米汽车成功的唯一途径就是挤进全球前五,否则打下来的根基都不会牢固。'[1]"

参考文献:
[1] 雷军:小米正式进入智能电动汽车行业,小米社区,2021年3月30日
```

### 4.4 历史事件核查

**核查要点**:
1. **时间准确性**
   - 年份
   - 具体月份甚至日期
   - 前后因果关系的时间逻辑

2. **事件细节**
   - 主要参与者
   - 关键决策
   - 结果影响

3. **多源验证**
   - 不同媒体的报道
   - 官方通报
   - 当事人回忆

**示例**:
```
❌ "2012年,白酒行业遭遇塑化剂风波..."

✅ "2012年11月19日,媒体曝光酒鬼酒塑化剂超标260%。隔天,白酒板块当日蒸发320亿元。一个月后,'八项规定'出台..."

来源:
[1] 酒鬼酒塑化剂超标,财新网,2012年11月19日
[2] 白酒板块暴跌,新浪财经,2012年11月20日
[3] 中央八项规定,新华网,2012年12月4日
```

## 五、参考文献管理

### 5.1 标注方法

**文中标注**:
```
在需要引用的句子/段落末尾,用[数字]标注。

示例:
"根据小米集团财报,三季度净亏损14.7亿元[1]。"
```

**同一来源多次引用**:
```
可使用同一数字,无需重复标注。

示例:
"小米净亏14.7亿[1]...应收账款拉长至62天[1]。"
```

### 5.2 文末列表格式

**标准格式**:
```
参考资料
[1] 文章/报告标题,来源机构/媒体,发布日期,URL
[2] 书名,作者,出版社,出版年份
[3] ...

示例:
参考资料
[1] 小米集团2022年第三季度业绩公告,小米集团,2022-11-23
[2] 京东的供应链革命,36氪,2021-11-08,https://...
[3] 《激荡三十年》,吴晓波,中信出版社,2007年
```

**分类列表**(适用于参考文献较多的情况):
```
参考资料

一、财报与公告
[1] 小米集团2022年Q3财报
[2] 京东集团2021年年报

二、媒体报道
[3] 江小白困局,财新周刊,2022-11-18
[4] 拼多多的逆袭,36氪,2023-01-05

三、研究报告
[5] 中国电商行业研究报告,艾瑞咨询,2022年
[6] 新消费品牌研究,华泰证券,2022年9月

四、书籍
[7] 《腾讯传》,吴晓波,浙江大学出版社,2017年
```

### 5.3 引用工具推荐

**Zotero**(免费,适合学术写作):
- 自动抓取网页信息
- 生成标准引用格式
- 浏览器插件支持

**印象笔记/Notion**:
- 灵活的笔记管理
- 方便粘贴链接
- 支持标签分类

**Excel表格**:
- 简单直观
- 便于分类筛选
- 适合批量管理

## 六、敏感信息处理

### 6.1 人物负面信息

**处理原则**:
- 必须有官方通报或法院判决
- 客观陈述事实,不添加主观评价
- 避免过度渲染
- 给予基本的人文关怀

**示例**:
```
❌ 错误:
"王效金贪污受贿,罪有应得..."

✅ 正确:
"2007年4月,王效金因涉嫌受贿被纪委带走。根据法院判决书,王效金被判处有期徒刑XX年。2023年,王效金在服刑期间因心脏病去世。"
```

### 6.2 企业财务数据

**处理原则**:
- 必须来自财报或监管文件
- 明确数据口径(GAAP/Non-GAAP)
- 避免选择性披露
- 不做未经审计的数据推算

**示例**:
```
✅ "根据未经审计的财务数据,江小白2020年营收约20亿元..."
✅ "按Non-GAAP标准,小米调整后净利润为21亿元..."
```

### 6.3 行业数据

**处理原则**:
- 注明统计口径和范围
- 说明时间周期
- 多个来源不一致时说明差异

**示例**:
```
✅ "据艾瑞咨询统计(统计口径:网络零售),2022年拼多多市占率为XX%。另一家机构易观的数据(统计口径:包含社交电商)显示为YY%。两个数据的差异主要源于统计口径不同..."
```

## 七、核查"三不原则"

### 原则1: 不虚构

**定义**: 绝不编造情节、对话、数据

**示例**:
```
❌ "在一次内部会议上,雷军拍着桌子说:'一定要做到世界第一!'"
(如无直接来源,这就是虚构)

✅ "雷军在公开场合多次强调小米的目标..."
```

### 原则2: 不夸大

**定义**: 客观陈述事实,不用夸张词汇

**示例**:
```
❌ "小米营收惊天暴跌,史无前例的灾难..."

✅ "小米营收同比下降11%,为近三年来最大降幅..."
```

### 原则3: 不臆测

**定义**: 对于无法证实的信息,明确标注

**示例**:
```
❌ "江小白裁员是因为资金链断裂..."
(无直接证据)

✅ "江小白传出裁员消息。据接近江小白的人士称,可能与业绩下滑有关,但公司未给出官方回应..."
```

## 八、常见问题Q&A

### Q1: 如果找不到一级信源怎么办?

**A**: 
1. 优先级降级使用二级信源
2. 至少找到2个二级信源交叉验证
3. 明确标注"据...报道"
4. 如果实在无法验证,放弃使用

### Q2: 数据在不同来源出现不一致怎么办?

**A**:
1. 检查统计口径是否一致
2. 优先采用官方/一级信源
3. 如差异较大,在文中说明
4. 示例:"不同机构对小米市占率的统计存在差异,本文采用XX机构的数据(统计口径:XX)"

### Q3: 企业不公开的数据如何处理?

**A**:
1. 非上市公司数据往往难以验证
2. 可使用"据...估算"、"市场传闻"等表述
3. 明确标注数据来源和可信度
4. 不可作为核心论据

### Q4: 如何处理"匿名消息"?

**A**:
1. 谨慎使用,必须标注"未经证实"
2. 尽快寻找官方信源验证
3. 如无法验证,仅作为参考,不作为论据
4. 示例:"有消息称XX,但截至发稿,公司尚未回应..."

## 九、核查效率提升技巧

### 9.1 建立常用数据库

**推荐数据库**:
- 上市公司财报: 巨潮资讯网、公司官网IR
- 行业数据: 国家统计局、各部委官网
- 法律文书: 中国裁判文书网
- 学术资料: 中国知网、谷歌学术

**收藏常用链接**:
```
浏览器书签分类:
- 财报查询
- 统计数据
- 行业报告
- 媒体资讯
```

## 十、核查时间管理

### 10.1 时间分配建议

**总写作时间**: 8小时
- 素材收集与核查: 3小时(37.5%)
- 框架搭建: 1小时(12.5%)
- 初稿写作: 2小时(25%)
- 修改打磨: 1.5小时(18.75%)
- 最终核查: 0.5小时(6.25%)

**核查不应该是最后一步**:
> "边写边查,效率最高。完稿后再查,往往发现大量需要修改的地方,得不偿失。"

### 10.2 紧急情况处理

**时间紧迫怎么办**:
1. 优先核查核心数据和论据
2. 次要细节可标注"待核实"
3. 发布后持续更新修正
4. 但绝不降低一级信源的使用标准

---

*事实核查是商业写作的生命线,任何时候都不能放松标准。*
