# 信息搜索方法论

## 一、搜索前的准备工作

### 1.1 明确研究对象和目标

在开始搜索前,先回答这些问题:

```markdown
## 研究对象定义清单

1. 研究主体是谁?
   - 公司全称/简称/英文名
   - 创始人姓名/核心高管
   - 主营业务/核心产品

2. 研究的时间范围?
   - 全生命周期(从成立至今)
   - 特定阶段(如2020-2023年转型期)
   - 某个关键节点(如上市前后)

3. 研究的核心问题?
   - 商业模式分析(如何赚钱)
   - 战略选择分析(为何成功/失败)
   - 行业地位分析(竞争格局)
   - 财务状况分析(盈利能力)

4. 预期产出是什么?
   - 5000字深度分析
   - 3000字快速解读
   - 系列专题报道
```

### 1.2 建立信息框架

**三层信息架构**:

```mermaid
graph TD
    A[第一层:基础信息] --> B[公司概况]
    A --> C[创始人背景]
    A --> D[主营业务]
    
    E[第二层:核心数据] --> F[财务数据]
    E --> G[市场数据]
    E --> H[运营数据]
    
    I[第三层:深度素材] --> J[战略转型]
    I --> K[关键事件]
    I --> L[人物故事]
    I --> M[行业洞察]
```

### 1.3 搜索关键词库

**基础关键词**:
- 公司全称+简称(中英文)
- 创始人姓名
- 核心产品名称
- 行业通用术语

**组合关键词**:
- "公司名+财报"
- "公司名+融资"
- "公司名+上市"
- "公司名+战略"
- "创始人+访谈"
- "创始人+演讲"

**进阶关键词**:
- "公司名+竞争对手"
- "公司名+供应链"
- "公司名+专利"
- "行业名+发展史"
- "行业名+竞争格局"

## 二、企业基础信息收集

### 2.1 工商信息查询

**主要平台**: 天眼查、企查查、爱企查

**核心信息提取**:

```markdown
## 工商信息清单

### 基本信息
- 公司全称: [法定名称]
- 成立时间: YYYY-MM-DD
- 注册资本: XXX万元
- 法定代表人: [姓名]
- 实际控制人: [姓名/机构]

### 股权结构
- 大股东及持股比例
- 关键投资机构
- 股权变更历史

### 经营状况
- 主营业务(工商登记)
- 对外投资企业
- 分支机构/子公司

### 风险信息
- 法律诉讼
- 被执行人信息
- 行政处罚
- 经营异常
```

**搜索技巧**:
- 通过"股权穿透"找到实际控制人
- 通过"对外投资"了解业务版图
- 通过"历史变更"还原发展轨迹
- 通过"关联企业"发现潜在风险

### 2.2 财务信息获取

**上市公司**(信息最全):

**核心渠道**:
1. 交易所官网: 上交所/深交所/港交所
2. 巨潮资讯网: 中国上市公司信息披露平台
3. 公司官网投资者关系页面
4. Wind/同花顺等金融终端(付费)

**必读文件**:
- 年度报告(最详细)
- 季度报告(追踪变化)
- 招股说明书(了解历史)
- 财报电话会议纪要(管理层观点)

**非上市公司**(信息有限):

**可获取渠道**:
1. 企查查/天眼查的"经营状况"
2. 工商年报(可能不完整)
3. 投资机构的公开披露
4. 媒体报道中的数据

### 2.3 创始人/高管背景调查

**信息来源**:

1. **公开履历**:
   - 公司官网"管理团队"页面
   - 上市公司公告(董事、高管简历)
   - LinkedIn/脉脉等职业社交平台

2. **深度访谈**:
   - 财经媒体专访(晚点、36氪、财新)
   - 行业峰会演讲实录
   - 视频访谈(YouTube、B站)

3. **历史报道**:
   - 早期创业报道(找到最初的媒体报道)
   - 人物特稿(深度人物刻画)
   - 校友会/企业家协会介绍

## 三、行业背景研究

### 3.1 行业发展史梳理

**研究路径**:

1. **查找行业综述报告**
   - 券商研报(如中信证券、国泰君安的行业深度报告)
   - 咨询公司报告(如麦肯锡、波士顿的行业研究)
   - 行业协会白皮书

2. **梳理关键时间节点**
   ```markdown
   ## 行业发展史模板
   
   ### 萌芽期(YYYY-YYYY)
   - 标志性事件: [第一家公司成立/第一款产品]
   - 市场规模: [初期体量]
   - 核心玩家: [早期企业]
   
   ### 成长期(YYYY-YYYY)
   - 标志性事件: [行业爆发/政策支持]
   - 市场规模增长: [年复合增长率]
   - 竞争格局: [新进入者/洗牌]
   
   ### 成熟期(YYYY-至今)
   - 标志性事件: [市场饱和/巨头垄断]
   - 当前市场规模: [最新数据]
   - 未来趋势: [技术变革/新模式]
   ```

3. **对比国际市场经验**
   - 美国同类行业发展路径
   - 日本同类行业经验教训
   - 欧洲市场的差异化特点

### 3.2 竞争格局分析

**数据来源**:

1. **市场份额数据**:
   - IDC/Gartner/Canalys(IT行业)
   - 艾瑞咨询/易观分析(互联网行业)
   - 中怡康/奥维云网(家电行业)
   - 尼尔森/凯度(消费品行业)

2. **竞争格局梳理框架**:

```markdown
## 竞争格局分析模板

### 市场集中度
- CR3(前三名市占率之和): XX%
- CR5(前五名市占率之和): XX%
- 市场格局: [一超多强/群雄逐鹿/寡头垄断]

### 主要玩家对比
| 企业 | 市占率 | 核心优势 | 主要劣势 | 战略方向 |
|------|--------|----------|----------|----------|
| 公司A | 30% | | | |
| 公司B | 25% | | | |
| 公司C | 15% | | | |

### 竞争维度分析
- 价格竞争: [是否价格战/毛利率水平]
- 技术竞争: [研发投入/专利数量]
- 渠道竞争: [线上线下布局]
- 品牌竞争: [品牌溢价能力]

### 行业壁垒
- 技术壁垒: [高/中/低]
- 资金壁垒: [高/中/低]
- 牌照壁垒: [是否需要]
- 规模效应: [是否明显]
```

### 3.3 产业链研究

**研究框架**:

```mermaid
graph LR
    A[上游供应商] --> B[核心企业]
    B --> C[下游渠道]

    A2[核心零部件] --> A
    
    C1[线上电商] --> C
    C2[线下门店] --> C
```

```markdown

### 下游渠道
```

## 四、关键事件研究

### 4.1 事件时间线构建

**搜索方法**:

1. **百度/谷歌时间筛选搜索**
   - 搜索"公司名+2020"(逐年搜索)
   - 使用"工具-时间范围"筛选

2. **企查查"企业动态"功能**
   - 自动整理融资、工商变更、新闻报道

3. **媒体数据库检索**
   - 晚点LatePost/36氪/财新的历史报道
   - 使用站内搜索功能

**事件时间线模板**:

```markdown
## 关键事件时间线

### 创立期(YYYY-YYYY)
- YYYY.MM: 公司成立,获天使轮融资XXX万
- YYYY.MM: 推出首款产品,获得XXX用户
- YYYY.MM: 完成A轮融资,估值达XXX亿

### 快速扩张期(YYYY-YYYY)
- YYYY.MM: 用户突破XXX万,成为行业第X
- YYYY.MM: 完成B轮/C轮融资,估值XXX亿
- YYYY.MM: 拓展新业务线/进入新市场

### 上市期/转型期(YYYY-YYYY)
- YYYY.MM: 提交IPO申请/宣布战略转型
- YYYY.MM: 成功上市,市值XXX亿
- YYYY.MM: [重大事件,如换帅/业务调整]

### 近期动态(YYYY-至今)
- YYYY.MM: [最新重要事件]
```

### 4.2 危机事件深度挖掘

**关键危机类型**:
- 财务危机(亏损、债务、裁员)
- 产品危机(质量问题、安全事故)
- 管理危机(内斗、离职、贪腐)
- 合规危机(监管处罚、法律诉讼)
- 舆情危机(公关灾难、信任崩塌)

**危机研究框架**:

```markdown

- 导火索: [什么引发了危机]

- 舆论反应: [媒体/用户的态度]
- 监管介入: [是否有官方调查]

### 公司应对
- 首次回应时间: [危机发生后XX小时]
- 回应态度: [道歉/辟谣/沉默]
- 实际行动: [召回/赔偿/整改]
- 高管表态: [CEO/董事长的公开发言]

### 事件影响
- 短期影响: [股价/营收/用户流失]
- 长期影响: [品牌形象/竞争地位]
- 行业影响: [是否引发监管/行业洗牌]

### 信源清单
- [ ] 官方公告
- [ ] 媒体报道(至少3家独立信源)
- [ ] 法院判决书(如涉及诉讼)
- [ ] 监管部门通报
```

## 五、数据可视化来源

### 5.1 财务数据可视化

**工具推荐**:
- 雪球/东方财富: 自动生成K线图、财务指标对比图
- Wind/同花顺: 专业金融图表
- Excel/Numbers: 自制图表

**常用图表类型**:

```markdown
## 财务数据可视化清单

### 营收增长趋势
- 图表类型: 柱状图+折线图(营收用柱状图,增长率用折线)
- 时间跨度: 近5年(按年)或近8个季度(按季)
- 数据来源: [财报名称+页码]

### 利润结构对比
- 图表类型: 堆叠柱状图
- 对比维度: 毛利/营业利润/净利润
- 数据来源: [财报名称+页码]

### 业务板块收入占比
- 图表类型: 饼图或环形图
- 展示内容: 各业务板块营收占比
- 数据来源: [财报名称+分部报告页码]

### 与竞争对手对比
- 图表类型: 雷达图或分组柱状图
- 对比指标: 营收/利润/研发投入/市值
- 数据来源: [多家公司财报]
```

- 行业协会: 产销量数据

**可视化示例**:

**可信度评级标准**:
- ★★★★★: 官方财报、政府文件、法院判决
- ★★★★☆: 权威媒体报道、券商研报、公司官宣
- ★★★☆☆: 一般媒体报道、行业专家观点
- ★★☆☆☆: 自媒体文章、社交媒体(需验证)
- ★☆☆☆☆: 匿名爆料、道听途说(慎用)

## 八、常见问题与解决方案

### 8.1 信息不足怎么办?

**问题**: 非上市公司财务数据无法获取

**解决方案**:
1. 通过融资新闻推算估值和体量
2. 从行业报告中找到市占率,反推营收
3. 从招聘信息推算人员规模
4. 从供应商/客户财报中找到关联交易数据
5. 直接联系公司PR部门申请数据

**问题**: 关键事件细节不清晰

**解决方案**:
1. 查找当时的多篇报道,交叉对比
2. 搜索当事人的微博/朋友圈(如有)
3. 在知乎/脉脉搜索相关讨论(谨慎采信)
4. 联系行业专家/前员工访谈

### 8.2 信息冲突怎么办?

**问题**: 不同信源的数据不一致

**解决方案**:
1. 优先采用一级信源(财报、官方文件)
2. 检查统计口径是否一致(如"中国市场"vs"全球市场")
3. 检查时间节点是否一致(如"2023年"vs"2023Q4")
4. 如无法确认,标注"据XX统计"并说明差异

**问题**: 媒体报道与官方说法矛盾

**解决方案**:
1. 呈现双方观点,不强行判断
2. 提供判断依据,让读者自己思考
3. 如有第三方证据(如法院判决),以证据为准
