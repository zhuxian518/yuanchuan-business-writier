# 框架生成器:从选题到大纲的全流程指南

## 一、框架生成器使用流程

### 1.1 系统概述

框架生成器是一个**交互式工具**,帮助你在30分钟内完成从选题确认到详细大纲的全流程。它整合了前面所有知识库的精华,通过结构化问答生成定制化的写作框架。

**核心功能**:
1. 选题可行性评估
2. 信息收集路径图生成
3. 文章大纲自动生成
4. 写作指导清单输出
5. 素材管理模板提供

### 1.2 三步生成法

```mermaid
graph LR
    A[Step1:选题输入] --> B[Step2:智能分析]
    B --> C[Step3:大纲输出]
    
    A1[公司/事件信息] --> A
    A2[写作目标] --> A
    
    B1[可行性评估] --> B
    B2[信息路径规划] --> B
    B3[框架类型匹配] --> B
    
    C --> C1[详细大纲]
    C --> C2[素材清单]
    C --> C3[写作指导]
```

## 二、Step 1: 选题信息收集

```markdown

### 2. 写作动机
- 选题契机: [财报发布/重大事件/行业趋势]
- 核心问题: [想解答什么问题,1-2句话]
- 目标读者: [创业者/投资人/普通读者]

### 3. 时间范围
- 重点时期: [全生命周期/近3年/某个转折点]

### 4. 预期产出
- 目标字数: [3000字/5000字/8000字]
```

### 2.2 选题类型判断

根据研究对象和核心问题,系统会自动判断文章类型:

| 类型 | 特征 | 典型案例 | 推荐字数 |
|------|------|----------|----------|
| **财报分析类** | 基于最新财报,分析经营状况 | 《小米:日子过得不好,但我还有救》 | 3000-5000字 |
| **战略分析类** | 聚焦企业战略选择和竞争策略 | 《京东的低价长跑》 | 5000-6000字 |
| **企业兴衰类** | 梳理企业发展史,分析成败原因 | 《谁打垮了江小白》 | 5000-8000字 |
| **行业趋势类** | 分析行业变革和未来方向 | 《新能源车的下半场》 | 5000-7000字 |
| **人物传记类** | 聚焦创始人/CEO的成长和决策 | 《雷军这十年》 | 6000-8000字 |
| **商业模式类** | 拆解企业如何赚钱和创造价值 | 《瑞幸的瓶颈期》 | 4000-6000字 |
| **事件复盘类** | 还原重大商业事件来龙去脉 | 《特斯拉降价风波》 | 3000-5000字 |

## 三、Step 2: 智能分析

### 3.1 可行性评估

系统会从三个维度评估选题可行性:

**维度1: 信息丰富度** (⭐⭐⭐⭐⭐ 满分5星)

- ⭐⭐⭐⭐⭐: 上市公司+近期财报+多篇深度报道
- ⭐⭐⭐⭐☆: 上市公司但财报较旧/非上市但有详细融资信息
- ⭐⭐⭐☆☆: 有基础工商信息+部分媒体报道
- ⭐⭐☆☆☆: 信息稀缺,只有零星报道
- ⭐☆☆☆☆: 几乎无公开信息

**建议**: ⭐⭐⭐以上可以写,⭐⭐以下建议换选题

**维度2: 时效性** (高/中/低)

- **高**: 近1个月内有重大事件(财报/融资/危机/战略调整)
- **中**: 近3-6个月内有新动向
- **低**: 无最新动态,纯历史回顾

**建议**: 时效性高更容易传播,但低时效性不影响深度价值

**维度3: 争议性/话题性** (高/中/低)

- **高**: 舆论关注度高,有多方观点碰撞
- **中**: 行业内关注,但大众认知不足
- **低**: 小众话题,受众有限

**建议**: 争议性高更易传播,但需要更谨慎的事实核查

### 3.3 框架类型匹配

系统会根据选题特征,推荐最合适的文章框架:

**框架1: 问题-分析-案例(PAC)框架**

**适用**: 财报分析类、战略分析类
**结构**:
1. 开篇:抛出核心矛盾/问题
2. 问题分析:为什么会这样?(数据+逻辑)
3. 案例支撑:其他公司的类似经历
4. 解决方案:公司如何应对?
5. 结尾:未来展望

**框架2: 时间线叙事(Timeline)框架**

**适用**: 企业兴衰类、人物传记类
**结构**:
1. 开篇:最戏剧化的时刻
2. 回溯:创立期的初心和选择
3. 发展:快速扩张的关键节点
4. 转折:危机或战略调整
5. 现状:当下面临的挑战
6. 结尾:历史的启示

**框架3: 对比论证(Comparison)框架**

**适用**: 行业趋势类、商业模式类
**结构**:
1. 开篇:行业现状的矛盾点
2. 对比1:不同公司的战略差异
3. 对比2:不同模式的利弊分析
4. 对比3:中国vs国际经验
5. 结尾:趋势判断

**框架4: 解构重组(Deconstruction)框架**

**适用**: 商业模式类、战略分析类
**结构**:
1. 开篇:表象与本质的反差
2. 解构1:商业模式的核心要素
3. 解构2:竞争优势的来源
4. 解构3:风险和隐忧
5. 重组:全景式评估
6. 结尾:价值判断

```markdown
- [ ] 核心数据是否准确?(已交叉验证)

- [ ] 金句是否恰当?(2-4个,不滥用)

### 事实检查
- [ ] 所有数据都有来源标注
- [ ] 所有时间节点已核实
- [ ] 所有人名/公司名无错别字
- [ ] 争议性内容已标注"有观点认为"
```

### 5.1 财报分析类示例

**输入信息**:
- 公司:小米集团
- 事件:2023年年报发布

**系统输出**:

```markdown

"2023年,小米营收2709亿,重回全球手机前三;但扣除投资收益后,经营利润同比暴跌67%,十年来最惨烈的一次。雷军在发布会上谈笑风生,财报电话会上却坦承'手机业务压力巨大'。这是小米最分裂的一年:表面风光,内里焦虑。"

## 二、背景铺陈 600字
1. 小米基本信息(100字)
2. 2023年手机行业格局(300字)
   - 全球手机出货量下滑3.2%
   - 中国市场竞争白热化:华为回归+荣耀崛起
   - 高端化成为行业共识
3. 引出问题(200字)
   - 小米为什么增收不增利?
   - 高端化战略遇到了什么困境?

## 三、正文模块1: "风光的营收,惨淡的利润" 1000字
1. 数据拆解(400字)
   - 营收2709亿(+4.9%),但经营利润暴跌67%
   - 手机ASP(平均售价)下滑,低端机占比上升
   - 毛利率20.8%,低于苹果(45%)和华为(40%)
2. 原因分析(400字)
   - 高端机(4000+)销量不及预期,小米14系列遇冷
   - 中低端市场价格战激烈,被迫降价保份额
   - 研发和营销费用大增,侵蚀利润
3. 小结(200字)
   - 小米陷入"高不成低不就"的尴尬境地

## 四、正文模块2: "高端化的困境" 1000字
1. 小米高端化三年回顾(300字)
   - 2021:小米11冲击高端
   - 2022:小米12系列+徕卡加持
   - 2023:小米14系列澎湃OS
2. 为什么高端化这么难?(500字)
   - 品牌认知壁垒:用户心智难改变
   - 产品力不足:对比iPhone和华为Mate
   - 渠道劣势:线下门店覆盖不足
3. 竞品对比(200字)
   - vivo/OPPO的高端化路径
   - 华为回归的冲击

## 五、正文模块3: "造车是解药还是毒药" 1000字
1. 小米汽车进展(300字)
   - 累计投入100亿
   - 预计2024年Q1交付
   - 目标:年销10万辆
2. 造车的机会(300字)
   - 新能源车高端市场空间大
   - 小米生态优势
   - 雷军的决心和资源投入
3. 造车的风险(400字)
   - 短期继续亏损,拖累财报
   - 竞争激烈,成功不确定
   - 分散管理层精力

## 六、结尾升华 400字
1. 回扣主题(150字)
   - 小米当下很难,但未来有希望
   - 手机业务需要突破,汽车业务需要耐心
2. 哲理升华(200字)
   - "所有的伟大公司,都曾经历至暗时刻"
```

## 八、常见问题与解决方案

### Q1: 素材不足,大纲无法填充怎么办?

**解决方案**:
1. 调整文章类型(如从8000字深度改为5000字解读)
2. 缩小研究范围(如从全生命周期聚焦到近3年)
3. 增加对比维度(如加入竞品对比,丰富内容)
4. 延长素材收集时间,挖掘更多信源

### Q2: 大纲看起来很散,逻辑不连贯?

**解决方案**:
1. 检查每个模块是否都回扣核心问题
2. 加强段落间的过渡句
3. 确保每个模块的小标题呼应总标题
4. 用一句话梳理全文逻辑主线

### Q3: 不知道选哪个开篇手法?

**建议**:
- 如果有戏剧化事件→用场景切入
- 如果数据反差大→用对比切入
- 如果有惊人数字→用数据震撼
- 都不明显→用对比切入(最保险)

### Q4: 结尾升华太难,写不出深度?

**解决方案**:
1. 从具体到抽象:从案例上升到规律
2. 从过去到未来:从历史教训到趋势展望
3. 从公司到行业:从个体困境到共性问题
4. 反问留白:抛出未解决的问题
