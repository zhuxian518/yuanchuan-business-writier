## 二、开篇引子模板

### 2.1 戏剧化场景模板

**模板A: 冲突场景**
```
在[地点],一场[事件]正在发生。

[细节1],[细节2],[细节3]。

这是[主体]的[状态描述],也是[行业/领域]的[缩影/转折点]。
```

**示例**:
```
在北京亦庄的一间会议室里,小米高管们正在盯着大屏幕上跳动的数字。

营收下滑11%,净利润为负,库存却增加了15%。

这是小米的至暗时刻,也是整个国产手机行业的严冬缩影。
```

**模板B: 死亡/重大事件开场**
```
[时间],[地点],一名叫[人物]的[身份]死了/[重大事件发生]。

[细节描述]。

[数据/时间跨度],[情感克制的补充说明]。
```

**示例**:
```
在合肥蜀山监狱的一个角落里,一名叫王效金的犯人死了。

尽管获得了两次减刑,但他还是在出狱前的两个月突发心脏病去世。

16年牢狱生涯,这位曾经的白酒英雄最终没能走出铁窗。
```

### 2.2 数据震撼模板

**模板A: 对比型**
```
[数据1]对[数据2],这是[主体A]和[主体B]的[指标]差距。

[解读这个差距意味着什么]。

而在[时间]之前,[情况描述],为什么会发生如此巨变?
```

**示例**:
```
22元对1456元,这是小米和苹果的单机利润差距。

这意味着小米要卖65部手机,才能赚到苹果一部手机的钱。

而在三年前,小米的单机利润还有50元,为什么会发生如此巨变?
```

**模板B: 趋势型**
```
从[时间1]到[时间2],[主体]的[指标]从[数据1]变化到[数据2],【倍数/百分比】。

这个数字背后,[揭示的趋势/问题]。

[引出核心问题]
```

**示例**:
```
从2019年到2023年,拼多多的GMV从1万亿飙升至4万亿,四年翻了两番。

这个数字背后,是下沉市场的觉醒,更是中国消费分级的真实写照。

但光靠低价,拼多多还能走多远?
```

### 2.3 对比反差模板

**模板A: 今昔对比**
```
[时间1],[主体]还是[状态A]。[具体描述]。

而如今,[主体]已经变成了[状态B]。[具体描述]。

从[A]到[B],中间到底发生了什么?
```

**示例**:
```
两年前,江小白还是白酒界的网红,文案刷屏社交媒体,销量年年攀升。

而如今,江小白陷入裁员风波,营收从30亿腰斩至20亿,曾经的年轻人都去喝精酿了。

从网红到过气,中间到底发生了什么?
```

**模板B: 认知颠覆**
```
人们以为[常见认知]。

但[数据/事实]却显示,[真实情况],这与[常见认知]恰恰相反。

这种反差背后,[引出核心问题]。
```

**示例**:
```
人们以为京东走的是"高质高价"路线。

但第三方比价数据却显示,在手机、家电、食用油等100个热门单品中,京东价格占优的比例都排名第一,这与"高定价"的印象恰恰相反。

这种反差背后,是京东供应链效率的持续优化。
```

## 三、正文模块模板

### 3.1 问题-分析-案例模板

**结构**:
```
模块小标题: [4-8字,制造悬念]

【问题提出】(1-2段)
[主体]面临的核心问题是[问题描述]。[数据/现象支撑]。

【多维分析】(3-5段)
原因一:[分析1],[支撑论据]。
原因二:[分析2],[支撑论据]。
原因三:[分析3],[支撑论据]。

【案例支撑】(2-3段)
具体来看,[案例描述]。[细节展开]。[案例与观点的关联]。

【小结过渡】(1段)
[总结本模块核心观点],[引出下一模块]。
```

**示例**:
```
### 再穷不能穷造车

小米真的因为卖手机而亏钱吗?答案是:不完全是。与二季度相比,小米毛利率环比仅下降0.2%至16.6%。

造成亏损的,来自两个直接数据:一是投资公允价值变动环比由正转负,三季度形成亏损近24亿元。二是研发费用的增加,三季度同比增加25.8%至41亿元。

其中以电动汽车为主的创新业务投入约8.3亿元。根据小米官方数据,前三季度,小米在造车业务上已投入18.6亿元。

也就是说,在未来相当长一段时间里,造车项目无疑将持续压制小米的盈利水平。并且直到小米的汽车量产之前,研发都将持续吞噬小米的利润。

更何况,量产也未必意味着成功。雷军自己知道:小米造车成功的唯一途径是挤进世界前五。
```

### 3.2 时间线叙事模板

**结构**:
```
模块小标题: [时间跨度+核心事件]

【时间起点】(1段)
[时间1],[背景描述],[起始状态]。

【关键节点1】(2-3段)
[时间2],[事件描述],[分析评论],[影响]。

【关键节点2】(2-3段)
[时间3],[事件描述],[分析评论],[影响]。

【关键节点3】(2-3段)
[时间4],[事件描述],[分析评论],[影响]。

【时间终点】(1-2段)
[时间5/如今],[现状描述],[趋势判断]。
```

**示例**:
```
### 江小白的黄金五年

2012年,江小白诞生。这一年的11月,白酒行业遭遇塑化剂风波,酒鬼酒塑化剂超标260%的新闻震惊全国,白酒板块当日蒸发320亿元。

一个月后,"禁酒令"、"八项规定"出台,连环重拳锤向白酒业。出厂价819元的飞天茅台,家门口的烟酒店850元就能买到。

2013-2017年,当一众酒企销量腰斩之时,初出茅庐的江小白却迎来了逆势增长。新品牌撇清和塑化剂的关系轻而易举,上不了领导酒桌反倒成了好事。

2018年,转折点来临。B站上市,Z世代营销正式被品牌们重视起来。江小白所在的年轻人市场一改往日的门庭冷落,变得异常拥挤。

如今,五花八门的精酿啤酒、预调鸡尾酒和小酒馆都在抢夺年轻人的酒杯,江小白的黄金时代已经过去。
```

### 3.3 对比论证模板

**结构**:
```
模块小标题: [对比主体A vs B]

【建立对比维度】(1段)
[对比的维度/标准是什么],[为什么选这个维度]。

【主体A的做法】(2-3段)
[主体A]的策略是[描述]。[具体展开],[数据/案例支撑]。

【主体B的做法】(2-3段)
[主体B]的策略是[描述]。[具体展开],[数据/案例支撑]。

【结果对比】(2-3段)
不同的选择带来了不同的结果:[主体A]实现了[结果A],[主体B]则[结果B]。

【揭示底层逻辑】(1-2段)
这种差异的本质在于[深层原因],[升华/延伸]。
```

## 四、结尾升华模板

### 4.1 哲理升华模板

**模板A: 古诗词/名言型**
```
[回顾全文核心观点],这不仅是[主体]的故事,更是[更大范畴]的缩影。

[引入古诗词/名言],放在今天来看,[与文章主题的关联]。

[最后一句话],[留下余韵]。
```

**示例**:
```
胖东来的兴起与永辉的困境,不仅是零售业的故事,更是时代情绪的投射。

"时来天地皆同力,运去英雄不自由。"放在今天来看,胖东来从未改变,永辉们也并未做错什么,潮起潮落从来都身不由己。

符号和偶像是时代思潮的浓缩,而商业的本质,终究还是要回归效率与价值。
```

**模板B: 从具体到抽象**
```
[主体]的经历告诉我们,[具体启示]。

但跳出[主体]这个案例,我们会发现,[更普遍的规律]。

[最后一句话],[开放性思考]。
```

### 4.2 展望未来模板

**模板A: 指向可能性**
```
[主体]的未来会如何,[不轻易下结论]。

但可以确定的是,[已经发生的变化],[未来的趋势]。

[最后一句话],[诗意化表达/数据化预测]。
```

**示例**:
```
小米的造车业务能否成功,现在下结论为时尚早。

但可以确定的是,中国汽车产业的格局正在重塑,新能源的窗口期不会等人太久。

行百里者半九十,不妨给小米十年时间。
```

**模板B: 与开篇呼应**
```
文章开头,我们看到了[开篇场景/问题]。

如今,[情况的变化],[意义]。

[与开篇形成呼应的最后一句话]。
```

### 4.3 人文关怀型模板

**模板**:
```
在[宏大叙事]背后,是一个个[具体的人/企业]的命运。

[人物/企业]的选择,映射了[时代特征/行业规律]。

[短句收尾],[余韵]。
```

**示例**:
```
在白酒行业的大浪淘沙背后,是王效金、袁仁国们的人生起伏。

他们的兴衰,既是个人选择的结果,也是时代洪流的必然。

酒香仍存,盛筵难再。
```

### 4.4 反问/留白型模板

**模板A: 直接反问**
```
[回顾全文],我们不禁要问:[核心问题]?

这个问题,[可能的答案1],也可能是[可能的答案2]。

[留白,不给确定答案]。
```

**示例**:
```
回顾江小白的十年,我们不禁要问:年轻人真的需要白酒吗?

这个问题,可能是营销的失败,也可能是品类的宿命。

有年轻人会用它来约会吗?
```

**模板B: 设置观察指标**
```
[主体]的命运,[不确定性]。

但有几个指标值得持续观察:[指标1],[指标2],[指标3]。

[最后一句话],[开放性结尾]。
```

## 五、段落写作模板

### 5.1 观点阐述段

**模板**:
```
[核心观点一句话陈述]。

[展开论述1],[支撑细节]。[展开论述2],[支撑细节]。

[数据/案例],[增强说服力]。

[小结/过渡句]。
```

### 5.2 数据对比段

**模板**:
```
数据是最好的证明。

[主体A]的[指标]是[数据1],[主体B]则是[数据2]。[对比解读]。

如果拉长时间维度来看,[趋势描述]:[时间1]是[数据],[时间2]是[数据]。

[一句话总结对比的意义]。
```

### 5.3 案例展开段

**模板**:
```
[引出案例的过渡句]。

以[具体案例]为例,[时间/背景],[主体]做了[动作]。[细节描述]。

这个案例的关键在于,[提炼要点],[与主题关联]。

[案例的启示/影响]。
```

### 5.4 转折过渡段

**模板**:
```
[前文小结]。

但,[转折词],[新的问题/矛盾]。

[展开新问题],[数据/现象支撑]。

[引出下文]。
```

## 六、快速启动模板

### 6.1 30分钟快速大纲模板

**用途**: 收到选题后快速搭建框架

```markdown
## 文章主题
[一句话概括]

## 核心观点
[你想说什么]

## 目标读者
[谁会看这篇文章]

## 信息收集清单
- [ ] 企业基本信息
- [ ] 关键时间节点
- [ ] 核心数据
- [ ] 竞品对比
- [ ] 专家观点

## 文章结构
1. 开篇: [切入角度]
2. 背景: [需要交代什么]
3. 模块1: [小标题] - [核心观点]
4. 模块2: [小标题] - [核心观点]
5. 模块3: [小标题] - [核心观点]
6. 结尾: [升华方向]

## 标题备选
1. [选项1]
2. [选项2]
3. [选项3]
```

### 6.2 写作检查清单模板

**用途**: 完成初稿后的自查

```markdown
## 标题检查
- [ ] 8-15字,简洁有力
- [ ] 制造张力/悬念
- [ ] 避免套路词汇

## 开篇检查
- [ ] 前3段内出现:事件+冲突+观点
- [ ] 前3句话出现核心主体
- [ ] 制造悬念或好奇
- [ ] 情感基调明确

## 正文检查
- [ ] 每个模块有明确小标题
- [ ] 观点-证据绑定
- [ ] 数据有对比/具象化
- [ ] 长短句配比合理(7:3)
- [ ] 每段最多2-3个数据

## 语言检查
- [ ] 删除冗余形容词
- [ ] 动词优先于名词化
- [ ] 段落节奏有变化
- [ ] 有2-4个核心金句

## 事实检查
- [ ] 所有数据有来源
- [ ] 人名/公司名/时间准确
- [ ] 因果关系严谨
- [ ] 参考文献完整

## 结尾检查
- [ ] 回扣主题
- [ ] 有升华或展望
- [ ] 留下余韵
- [ ] 不简单总结
```

## 七、分场景应用模板

### 7.1 财报分析类

**结构**:
```
标题: [公司名]+[财务状况判断]

开篇: 核心数据展示
背景: 行业环境/历史对比
模块1: 业绩拆解(收入/利润/现金流)
模块2: 业务分析(各板块表现)
模块3: 未来展望(机会/风险)
结尾: 投资建议/开放性思考

字数: 3000-4000字
数据密度: 高(每300字1个关键数据)
```

### 7.2 企业兴衰类

**结构**:
```
标题: 疑问句/感叹句

开篇: 戏剧化场景/对比反差
背景: 企业历史/行业地位
模块1: 兴起原因(时代/战略/运气)
模块2: 转折点(内忧/外患)
模块3: 衰落分析(战略失误/竞争加剧)
模块4: 启示与思考
结尾: 哲理升华/人文关怀

字数: 5000-6000字
叙事性: 强(时间线+人物+事件)
```

### 7.3 行业趋势类

**结构**:
```
标题: [行业关键词]+[趋势判断]

开篇: 现象/数据/案例
背景: 行业现状/发展史
模块1: 驱动因素(技术/政策/需求)
模块2: 典型玩家分析(3-5家)
模块3: 未来趋势预判
结尾: 开放性展望

字数: 4000-5000字
数据+案例并重
```

### 7.4 商业模式类

**结构**:
```
标题: [主体]+[模式特征]

开篇: 核心逻辑展示
背景: 行业痛点/机会
模块1: 模式拆解(怎么做)
模块2: 竞争优势(为什么行)
模块3: 可持续性分析(能走多远)
结尾: 可复制性/边界讨论

字数: 4000-5000字
逻辑性:强(层层递进)
```
