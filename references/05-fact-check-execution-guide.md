# 事实核查执行指南

## 一、核查前准备

### 1.1 核查清单生成

在开始写作前,先建立待核查内容清单:

```markdown
## 待核查清单模板

### 核心数据(必须核查)
- [ ] 财务数据: 营收/利润/增长率/市值
- [ ] 时间节点: 成立/融资/上市/重大事件
- [ ] 市场数据: 市占率/行业规模/用户数
- [ ] 人物信息: 姓名/职务/年龄/背景

### 事件描述(建议核查)
- [ ] 关键事件的时间、地点、人物
- [ ] 因果关系的逻辑链条
- [ ] 竞争对手的动作和反应

### 引用内容(必须溯源)
- [ ] 创始人/高管的公开发言
- [ ] 专家学者的观点
- [ ] 媒体报道的关键信息
```

### 1.2 信源工具包

**一级信源获取渠道**:

| 类型 | 渠道 | 适用场景 | 注意事项 |
|------|------|----------|----------|
| 上市公司财报 | 巨潮资讯网/交易所官网 | 所有财务数据 | 注意时间节点和统计口径 |
| 工商信息 | 天眼查/企查查 | 股权结构/法律诉讼 | 付费版信息更全 |
| 政府文件 | 各部委官网 | 政策法规/行业数据 | 注意发布时间和适用范围 |
| 法律文书 | 中国裁判文书网 | 法律纠纷/诉讼细节 | 可能有延迟或屏蔽 |

**二级信源获取渠道**:

| 类型 | 渠道 | 适用场景 | 注意事项 |
|------|------|----------|----------|
| 券商研报 | Wind/萝卜投研 | 行业分析/趋势判断 | 注意利益相关性 |
| 主流媒体 | 财新/36氪/晚点 | 深度报道/独家消息 | 交叉验证关键信息 |
| 行业报告 | 艾瑞/QuestMobile | 市场规模/用户画像 | 注意样本量和统计方法 |
| 公司官宣 | 官网/公众号/微博 | 战略动向/人事变动 | 可能有美化倾向 |

**三级信源(需谨慎使用)**:

- 自媒体文章: 仅作为线索,必须找到原始出处
- 社交媒体: 适合捕捉舆论风向,不能作为事实依据
- 匿名爆料: 除非有强证据支持,否则不采用
- 道听途说: 明确标注"据...称"或"传闻"

## 二、分类核查方法

### 2.1 财务数据核查

**核查步骤**:

1. **找到原始财报**
   - 上市公司: 交易所官网下载PDF版财报
   - 非上市公司: 工商年报(可能不完整)

2. **核对关键指标**
   ```markdown
   - 营收: 核对"营业收入"科目
   - 净利润: 核对"归属于母公司所有者的净利润"(扣非净利润更真实)
   - 增长率: 自行计算,注意同比/环比/复合增长率的区别
   - 市值: 注意时间节点(收盘价x总股本)
   ```

3. **注意常见陷阱**
   - 营收≠利润: 有些公司营收很高但亏损严重
   - 毛利率≠净利率: 别被高毛利率迷惑
   - 调整后净利润: 警惕"非经常性损益"的调整
   - 单季度vs全年: 别把单季数据当成全年

**案例示范**:

❌ 错误写法:
> "小米2023年营收突破3000亿,成为中国最赚钱的手机公司"

✅ 正确写法:
> "小米2023年全年营收2709亿元,同比增长4.9%;净利润162亿元,同比增长118.8%"(数据来源:小米集团2023年年报)

### 2.2 历史事件核查

**核查步骤**:

1. **确认时间节点**
   - 通过多个独立信源交叉验证
   - 优先采用当时的新闻报道(而非回忆性文章)
   - 注意"首次披露时间"vs"实际发生时间"

2. **还原事件全貌**
   - 不要只看单方说法
   - 寻找当事人的公开回应
   - 查阅同期的多篇报道

3. **谨慎判断因果关系**
   - "同时发生"≠"因果关系"
   - 避免过度简化复杂事件
   - 对争议性解读要标注"有观点认为"

**案例示范**:

❌ 错误写法:
> "2018年,因为中美贸易战,华为手机销量暴跌"

✅ 正确写法:
> "2019年5月,华为被列入美国商务部实体清单;当年第三季度,华为海外市场出货量下降16%"(数据来源:Canalys 2019 Q3报告)

### 2.3 人物语录核查

**核查步骤**:

1. **追溯原始出处**
   - 优先查找现场视频/演讲实录
   - 核对媒体报道是否断章取义
   - 注意"转述"和"直接引用"的区别

2. **标注引用来源**
   ```markdown
   - 直接引用: "创新是小米的生命线"(雷军,2023年小米发布会)
   - 间接引用: 雷军曾表示,创新对小米至关重要(据36氪2023年报道)
   - 媒体转述: 有媒体报道称,雷军在内部会议上强调创新的重要性
   ```

3. **避免过度解读**
   - 不要把"可能"说成"一定"
   - 不要把"暗示"说成"明确表态"
   - 对模糊表达保持原貌

**案例示范**:

❌ 错误写法:
> "马斯克说特斯拉将在2025年实现完全自动驾驶"

✅ 正确写法:
> "马斯克在2023年财报电话会上预测,特斯拉FSD有望在2024年底前实现无人监督的自动驾驶(注:马斯克此前多次推迟该时间表)"

### 2.4 行业数据核查

**核查步骤**:

1. **找到权威数据源**
   - 政府统计局: 宏观经济数据
   - 行业协会: 产销量/进出口数据
   - 调研机构: Gartner/IDC/艾瑞(注意样本量)

2. **核对统计口径**
   ```markdown
   - 市场规模: 是"出货量"还是"销售额"?
   - 增长率: 是"同比"还是"环比"?
   - 市占率: 分子分母的统计范围是否一致?
   - 排名: 是"全球"还是"中国"?按什么维度排?
   ```

3. **多个来源交叉验证**
   - 如果不同机构数据差异大,需说明原因
   - 优先采用官方/权威机构数据
   - 对争议数据标注"据...统计"

**案例示范**:

❌ 错误写法:
> "中国新能源车市场规模已超1000万辆"

✅ 正确写法:
> "据中汽协数据,2023年中国新能源汽车销量949.5万辆,同比增长37.9%;渗透率达31.6%"

## 三、核查执行流程

### 3.1 写作时同步核查(实时模式)

**操作方法**:

1. **每写一段立即核查**
   - 写完数据→立即查财报确认
   - 写完事件→立即查新闻报道
   - 写完引语→立即找原始出处

2. **建立"临时引用库"**
   ```markdown
   ## 临时引用库
   
   [1] 小米2023年营收2709亿元
       来源: 小米集团2023年年报 P.3
       链接: https://...
       提取时间: 2024-01-28
   
   [2] "创新是小米的生命线"
       来源: 雷军2023年发布会演讲
       视频: https://...
       时间点: 00:12:34
   ```

3. **不确定的内容先标记**
   - 用【待查】标记不确定的内容
   - 写完全文后集中核查

### 3.2 完稿后系统核查(集中模式)

**四轮核查法**:

**第一轮: 数据核查**
- 用搜索功能找出所有数字
- 逐个核对来源和准确性
- 检查单位是否统一(亿/万亿/美元/人民币)

**第二轮: 时间核查**
- 找出所有时间节点
- 确认"YYYY年"、"Q1-Q4"、"上半年"等表述准确
- 检查时间逻辑是否合理(前后矛盾)

**第三轮: 人名/公司名核查**
- 确认人名无错别字
- 确认职务/头衔准确(注意时间节点)
- 公司全称/简称统一

**第四轮: 引用溯源**
- 为所有引用添加出处标注
- 生成文末参考文献列表
- 删除无法找到出处的引用

### 3.3 核查报告模板

```markdown
## 事实核查报告

### 文章标题: [标题]
### 核查时间: YYYY-MM-DD
### 核查人: [姓名]

### 1. 核查概况
- 总字数: XXXX字
- 数据点: XX个(已核查XX个,待确认XX个)
- 引用来源: XX个
- 高风险点: XX个

### 2. 核查结果

#### 2.1 已确认准确
- [x] 小米2023年营收2709亿元 → 来源:年报P.3
- [x] 雷军"创新是生命线"引语 → 来源:2023发布会视频

#### 2.2 需要修正
- [ ] 原文:"市值突破万亿" → 实际:截至XX日市值9876亿
- [ ] 原文:"2022年融资" → 实际:2023年融资

#### 2.3 无法核实(建议删除)
- [ ] "内部人士透露..."
- [ ] "有消息称..."

### 3. 参考文献(自动生成)
[1] 小米集团. 2023年年度报告[R]. 2024-03-20.
[2] 雷军. 小米14发布会演讲[EB/OL]. 2023-10-26.
...
```

## 四、特殊场景处理

### 4.1 负面信息处理

**原则**: 客观、克制、有据可查

**注意事项**:
- 涉及法律纠纷: 必须引用法院判决书或官方通报
- 涉及经营困境: 必须有财报或权威媒体报道支持
- 涉及人物负面: 必须有当事人回应或官方说明
- 避免使用"据说"、"传闻"等模糊表述

**案例示范**:

❌ 错误写法:
> "江小白创始人陶石泉因管理混乱导致公司陷入困境"

✅ 正确写法:
> "据天眼查显示,江小白关联公司重庆江小白酒业于2023年被列为被执行人,执行标的XXX万元;公司未对此公开回应"

### 4.2 争议性观点处理

**原则**: 呈现多方观点,不强加结论

**处理方式**:
- 明确标注"有观点认为"、"业内人士分析"
- 同时呈现支持和反对的声音
- 提供判断依据,让读者自己思考

**案例示范**:

❌ 错误写法:
> "特斯拉FSD技术已经超越人类司机"

✅ 正确写法:
> "特斯拉宣称FSD Beta的事故率低于人类司机平均水平,但美国高速公路安全管理局(NHTSA)正在调查多起涉及FSD的事故;对于自动驾驶安全性的评估,业内尚未形成统一标准"

### 4.3 预测性内容处理

**原则**: 明确标注预测来源和假设条件

**处理方式**:
- 区分"事实"和"预测"
- 标注预测机构和时间
- 提示预测的不确定性

**案例示范**:

❌ 错误写法:
> "2025年中国新能源车渗透率将达50%"

✅ 正确写法:
> "据中汽协预测,2025年中国新能源汽车渗透率有望达到45%-50%(该预测基于当前政策和市场趋势,实际情况可能因政策调整、技术变革等因素发生变化)"

## 五、参考文献管理

### 5.1 引用标注方法

**行内标注**(推荐):

```markdown
小米2023年营收2709亿元,同比增长4.9%[1]。

[1] 小米集团. 2023年年度报告[R]. 2024-03-20.
```

**脚注标注**(适合长文):

```markdown
小米2023年营收2709亿元①,同比增长4.9%。

---
① 数据来源:小米集团2023年年报第3页
```

### 5.2 文末参考文献格式

**标准格式**:

```markdown
## 参考文献

[1] 作者. 文章标题[文献类型]. 出版地:出版者,出版年份.
[2] 作者. 文章标题[EB/OL]. 网址, 访问日期.

## 数据来源

- 财务数据: 小米集团2023年年报、巨潮资讯网
- 市场数据: IDC中国手机市场季度跟踪报告2023Q4
- 人物引语: 雷军2023年小米发布会演讲实录
```

**实际案例**:

```markdown
## 参考文献

[1] 小米集团. 2023年年度报告[R]. 2024-03-20.
[2] IDC. 中国手机市场季度跟踪报告2023Q4[R]. 2024-01-15.
[3] 雷军. 小米14发布会演讲实录[EB/OL]. https://..., 2023-10-26.
[4] 晚点LatePost. 小米造车三年[J/OL]. https://..., 2024-01-10.
```

### 5.3 引用工具推荐

**自动生成工具**:
- Zotero: 免费文献管理工具
- EndNote: 专业文献管理(付费)
- 百度学术/谷歌学术: 自动生成引用格式

**手动记录模板**:

```markdown
## 素材库模板

| 序号 | 内容类型 | 具体内容 | 来源 | 链接 | 提取时间 | 可信度 |
|------|----------|----------|------|------|----------|--------|
| 1 | 财务数据 | 营收2709亿 | 小米年报 | https://... | 2024-01-28 | ★★★★★ |
| 2 | 人物引语 | "创新是生命线" | 发布会 | https://... | 2024-01-28 | ★★★★★ |
| 3 | 市场数据 | 市占率14.5% | IDC报告 | https://... | 2024-01-28 | ★★★★☆ |
```

## 六、核查自检清单

### 写作完成后必查项

- [ ] 所有数字都有明确来源
- [ ] 所有时间节点已交叉验证
- [ ] 所有人名/公司名无错别字
- [ ] 所有引用都能追溯到原始出处
- [ ] 争议性内容已标注"有观点认为"
- [ ] 负面信息有官方文件或权威报道支持
- [ ] 文末参考文献列表完整
- [ ] 高风险内容(法律/财务/人物负面)已重点核查

### 发布前最后确认

- [ ] 再次核对核心数据(营收/利润/市值)
- [ ] 确认没有使用"据说"、"传闻"等模糊表述
- [ ] 确认敏感内容表述克制、有据可查
- [ ] 确认引用来源的链接有效
- [ ] 确认没有过度解读或臆测

---

**核查金句**:

> "写作时保持怀疑,发布前反复求证。宁可少写一个'惊人发现',也不要留下一处事实漏洞。"

> "好的商业写作不是靠爆料取胜,而是靠扎实的事实和深刻的洞察。"
