# 交互引擎模块

> **职责**：通过结构化提问收集用户需求，生成完整的文章生成配置对象

---

## 🎯 核心功能

交互引擎负责在用户输入选题后，通过5-8个精心设计的问题，快速明确：
- 研究对象的基本信息
- 用户的核心关注点
- 文章的生成级别和字数
- 素材获取方式
- 输出偏好

---

## 📋 提问流程设计

### 阶段一：选题确认（必问）

**Q1：研究对象确认**

```
您想研究的对象是：[用户输入的选题]

请确认以下信息：
1. 研究对象类型：
   - a) 单一公司（如"小米汽车"）
   - b) 行业趋势（如"新能源车行业"）
   - c) 商业模式（如"直播电商模式"）
   - d) 商业事件（如"硅谷银行倒闭"）
   - e) 企业家人物（如"雷军创业史"）

2. 所属行业/领域：[AI自动识别，用户可修改]

3. 是否有时间范围要求：
   - a) 最近1年内
   - b) 近3-5年
   - c) 完整发展史
   - d) 特定时间段（请说明）
```

**AI处理逻辑**：
- 根据用户选题自动识别类型（如"小米汽车"→单一公司）
- 自动识别行业（如"小米汽车"→新能源汽车行业）
- 提供确认选项，减少用户输入

---

### 阶段二：核心问题明确（必问）

**Q2：您最关心什么问题？**

```
关于[研究对象]，您最想弄清楚的是（可多选）：

针对公司类型：
- a) 商业模式是什么？为什么能赚钱？
- b) 竞争优势在哪里？护城河是什么？
- c) 发展历程中的关键转折点
- d) 当前面临的困境和挑战
- e) 未来发展趋势和机会
- f) 与竞争对手的对比分析

针对行业类型：
- a) 行业现状和竞争格局
- b) 技术变革和创新方向
- c) 政策影响和监管环境
- d) 未来5年的发展趋势

针对事件类型：
- a) 事件的前因后果
- b) 各方利益博弈
- c) 对行业的深远影响
- d) 历史相似案例对比

请选择1-3个核心问题（输入字母，如"a,c,e"）
```

**AI处理逻辑**：
- 根据Q1的类型，动态展示不同选项
- 用户选择后，AI生成核心观点方向
- 示例：用户选"a,b"→文章将聚焦"商业模式和竞争优势"

---

### 阶段三：生成级别选择（必问）

**Q3：选择生成级别**

```
请选择文章生成级别：

📘 基础版（推荐新手/快速解读）
   - 字数：5000-6000字
   - 时间：3-4小时完成
   - 特点：结构完整，逻辑清晰，适合快速了解
   - 数据：核心数据+基础对比
   - 案例：1-2个典型案例
   
📗 进阶版（推荐深度分析）⭐ 默认推荐
   - 字数：8000-10000字
   - 时间：6-8小时完成
   - 特点：深度剖析，数据丰富，观点鲜明
   - 数据：多维度数据+行业对比+趋势分析
   - 案例：3-5个典型案例+细节刻画
   
📕 专业版（推荐资深研究者）
   - 字数：10000+字
   - 时间：需要2-3天完成
   - 特点：全景式解析，包含多轮事实核查和专家视角
   - 数据：完整数据库+财务模型+预测分析
   - 案例：6+个案例+深度访谈引用

请输入a/b/c（不输入默认选b）：
```

**AI处理逻辑**：
- 默认推荐"进阶版"（符合远川文章平均长度）
- 根据用户选择，后续调整素材收集深度和生成细节

---

### 阶段四：素材获取方式（必问）

**Q4：素材获取方式**

```
关于[研究对象]的素材，您希望：

a) 完全自动搜索 ⭐ 推荐
   - AI自动联网搜索财报、新闻、研报等公开资料
   - 优点：省时省力，覆盖全面
   - 注意：AI会尽力确保准确性，但建议您最后核对关键数据

b) 您提供核心素材，AI补充
   - 您提供关键信息（如财报数据、内部资料）
   - AI负责搜索背景、行业、对比等辅助素材
   - 优点：核心数据更可靠

c) 混合模式
   - AI先自动搜索，生成素材清单
   - 您审核并补充，AI再基于更新后的素材生成

请输入a/b/c（不输入默认选a）：
```

**AI处理逻辑**：
- 选a：直接进入自动搜索流程
- 选b：询问用户"请提供您掌握的核心素材"
- 选c：先搜索生成清单，等待用户审核后再继续

---

### 阶段五：文章类型偏好（可选，AI智能推荐）

**Q5：文章类型偏好**

```
基于您的选题和关注点，我推荐以下文章类型：

推荐：[财报解读型] / [战略分析型] / [兴衰史型] / [趋势洞察型] ...

常见文章类型：
a) 财报解读型 - 深挖财务数据，揭示经营真相
   示例：《比亚迪2023：一场垂直整合的胜利》
   
b) 战略分析型 - 拆解商业逻辑，分析竞争策略
   示例：《小米汽车：亏本卖车的生态算盘》
   
c) 兴衰史型 - 回溯发展历程，复盘关键决策
   示例：《诺基亚沉没记：错过的不只是安卓》
   
d) 趋势洞察型 - 行业全景扫描，预判未来方向
   示例：《2024，新能源车进入淘汰赛》
   
e) 人物传记型 - 聚焦企业家，刻画性格与选择
   示例：《雷军这十年：从谷底到巅峰的坚持》
   
f) 模式拆解型 - 解构商业模式，揭示盈利秘密
   示例：《拼多多的下沉市场密码》
   
g) 事件复盘型 - 还原事件过程，分析深层原因
   示例：《硅谷银行倒闭72小时》

如果您认可推荐类型，直接回车；
如果想选择其他类型，请输入字母（a-g）：
```

**AI处理逻辑**：
- 根据Q1和Q2自动推荐最合适的类型
- 示例：选题"小米汽车"+关注"商业模式"→推荐"战略分析型"
- 用户可接受推荐或自主选择

---

### 阶段六：特殊要求收集（可选）

**Q6：是否有特殊要求？**

```
最后，如果您有以下特殊要求，请告知：

1. 目标读者定位：
   - a) 普通大众（深入浅出，少用专业术语）
   - b) 行业从业者（可使用行业黑话）
   - c) 投资者（侧重财务和估值分析）
   - d) 创业者（侧重战略和方法论）

2. 文章基调：
   - a) 客观中立（理性分析，不带倾向）⭐ 默认
   - b) 批判质疑（指出问题和风险）
   - c) 肯定赞扬（突出成就和亮点）

3. 是否需要对比竞品：
   - a) 是，请列出2-3个对比对象
   - b) 否，聚焦单一对象

4. 其他要求（可选）：
   - 例如：必须引用某个数据、避开某个敏感话题等

如无特殊要求，直接回车跳过：
```

**AI处理逻辑**：
- 默认值：普通大众+客观中立+不对比
- 用户可按需调整

## 🔧 配置对象生成

根据用户回答，生成完整配置对象：

```typescript
interface ArticleGenerationConfig {
  // 选题信息
  topic: {
    subject: string;              // 研究对象
    type: 'company' | 'industry' | 'model' | 'event' | 'biography';
    industry: string;             // 所属行业
    timeRange: string;            // 时间范围
    coreQuestions: string[];      // 核心问题列表
  };
  
  // 生成参数
  generation: {
    level: 'basic' | 'advanced' | 'professional';
    targetWords: {
      min: number;
      max: number;
    };
    estimatedTime: string;        // 预计完成时间
  };
  
  // 文章设定
  article: {
    type: 'financial' | 'strategic' | 'history' | 'trend' | 'biography' | 'model' | 'event';
    audience: 'general' | 'professional' | 'investor' | 'entrepreneur';
    tone: 'neutral' | 'critical' | 'positive';
    needComparison: boolean;
    competitors?: string[];       // 对比对象
  };
  
  // 素材设定
  material: {
    source: 'auto' | 'provided' | 'hybrid';
    providedData?: any;           // 用户提供的素材
    searchPriority: string[];     // 搜索优先级
  };
  
  // 输出设定
  output: {
    mode: 'dialogue' | 'file' | 'both';
    filename?: string;
    includeReferences: boolean;   // 是否包含参考文献
    includeDataSource: boolean;   // 是否包含数据源清单
  };
  
  // 特殊要求
  special?: {
    mustInclude?: string[];       // 必须包含的内容
    mustAvoid?: string[];         // 必须避开的内容
    customRequirements?: string;  // 其他自定义要求
  };
}
```

## 🚀 使用方式

### 在SKILL.md中调用

```markdown
## 步骤1：需求收集

当用户输入选题后，系统自动加载[module:interaction-engine]：

1. 识别选题类型（公司/行业/事件/人物等）
2. 依次展示Q1-Q6问题
3. 根据用户回答生成ArticleGenerationConfig对象
```

## 💡 设计亮点

1. **智能推荐**：AI根据选题自动推荐最合适的类型和参数
2. **默认值优化**：每个问题都有合理默认值，减少用户输入
3. **渐进式提问**：必问→推荐→可选，避免信息过载
4. **配置可视化**：生成配置对象后，用Markdown表格展示，方便确认
5. **灵活调整**：用户可随时修改某个配置项，无需重新回答所有问题

## 📝 输出检查清单

生成配置对象后，系统自动检查：

- [ ] 选题明确，无歧义
- [ ] 核心问题至少1个
- [ ] 生成级别已确认
- [ ] 字数范围合理（最低5000字）
- [ ] 素材来源已明确
- [ ] 输出模式已选择
- [ ] 特殊要求已记录（如有）

检查通过后，提示用户："✅ 配置完成！预计生成[字数]字文章，耗时[时间]。是否开始？"
