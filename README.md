## ⚠️ 重要提示

### 1. 数据准确性

- ✅ 所有数据自动联网搜索并多源验证
- ✅ 单一信源自动标记"待验证"
- ✅ 冲突数据提示用户确认
- ⚠️ AI尽力确保准确,但建议最终核对关键数据

### 2. 信源可靠性

| 级别 | 类型 | 使用方式 |
|------|------|----------|
| ⭐⭐⭐⭐⭐ | 上市公司财报、政府文件 | 直接引用 |
| ⭐⭐⭐⭐ | 券商研报、主流媒体 | 标注来源 |
| ⭐⭐⭐ | 行业媒体、专业机构 | 需交叉验证 |
| ⭐⭐ | 自媒体、社交媒体 | 仅作参考 |
| ⭐ | 匿名爆料、网络传言 | 不使用 |

### 3. 敏感信息处理

- 负面信息必须有权威媒体报道
- 必须标注"据XX报道",不做主观判断
- 禁用"知情人士"、"有消息称"等模糊信源
